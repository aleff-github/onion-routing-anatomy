# GitHub repository settings (proposal)

To be applied by the repository owner when the repository becomes public.

**Description**

> Onion Routing Anatomy — a free, GPL-licensed technical book on the Tor protocol, byte by byte (Italian edition), with 20 reproducible labs on a private Tor network.

**Website:** the GitHub Pages address, once the site is published and verified
(`docs/maintainers/github-pages.md`); expected `https://aleff-github.github.io/onion-routing-anatomy/`.

**Topics**

`tor` · `onion-routing` · `anonymity` · `privacy` · `cryptography` · `network-security` ·
`python` · `technical-book` · `cybersecurity`

**Social preview:** upload `assets/social-preview.png` (1280×640) in
*Settings → General → Social preview*.

**Releases:** procedure and checklist in [`release-procedure.md`](release-procedure.md).

**Issues and labels:** issue forms are in `.github/ISSUE_TEMPLATE/`. The labels they use
(`typo`, `translation`, `technical`, `laboratory`, `documentation`, `proposal`), the
`status: …` labels and the `lang: …` labels ([`editorial-process.md`](../editorial-process.md))
were created in this repository on 29 October 2026 with `sh scripts/github_labels.sh`
(needs the `gh` command, authenticated as an administrator); running it again only updates
colours and descriptions.

**Security:** once the repository is public, enable *Settings → Code security → Private
vulnerability reporting* ([`../SECURITY.md`](../../SECURITY.md)).

**Pages:** [`github-pages.md`](github-pages.md).
