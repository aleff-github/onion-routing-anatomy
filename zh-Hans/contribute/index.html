帮助改进本书

本书是一部自由作品，欢迎读者通过修改说明、代码或实验内容参与改进。

参与方式

  • 报告错别字拼写错误、漏字、表述不清的句子。
  • 修正译文译本中错误或不自然的段落。
  • 技术勘误关于 Tor 的错误或过时的说法。
  • 实验问题与描述不符的实验。
  • 提出改进新内容、更好的解释、一幅插图。
  • 译本审校审校你所用语言的某一章。
  • 贡献文字或代码提交一个 pull request。
  • 改进文档README、指南、说明。

不用 Git 和 LaTeX

你只需要一个 GitHub 账号。选择反馈类型，填写表单——语言、章节或页码、现有文字以及你建议的写法——然后提交即可。修改源文件的工作会由其他人完成。

对于小的错别字，你也可以自己提出修改：在 GitHub 上打开文件，点击铅笔图标，修改文字，然后选择“Propose changes”。GitHub 会自动为你创建仓库副本和 pull request，无需编译本书。

使用 Git

  1. 除非只是小修改，请先创建一个 issue。
  2. 找到文件：意大利语正文在 source/it/，译本在 source/<语言>/，实验代码在 labs/。
  3. fork 本仓库，创建分支并进行修改。
  4. 运行与修改相应的检查：make check 和 make test 只需要 Python；编译本书需要 Docker。
  5. 提交 pull request，并回复审阅意见。

详细说明见 CONTRIBUTING.md（英语和意大利语）。

之后会怎样

每一条反馈都会被阅读，并标记一个状态：待核实、已确认、处理中、 已提出修正、已解决、无法复现或重复。涉及协议描述、密码学或实验的修改，需要一手资料或可复现的证明；错别字只需快速核对。被采纳的修正会进入本书的下一个版本，并列入更新日志。具体流程见 docs/editorial-process.md。

致谢

修改被采纳的贡献者会列在 CONTRIBUTORS.md 中，使用其 GitHub 用户名或其自选的名字。任何人都可以要求不被列出。这里没有排名。

须知

  • 贡献内容按本项目的许可证 GPL-3.0-or-later 接受。
  • 请勿在公开的 issue 中发布个人数据、私钥、抓包文件或其他敏感材料。
  • 代码或实验中的安全问题请私下报告：见 SECURITY.md。
  • 所有人都应遵守简短的行为准则。
