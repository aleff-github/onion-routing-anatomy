图书内容

31 章、4 个附录、176 道分级习题（附答案）、39 幅原创插图。参考版本：tor 0.4.9.13 和 Arti 2.6.0。

本书面向具备网络（TCP/IP、TLS）和编程基础的大学生、安全从业者和研究人员。书中的技术论断都对应到一手资料——Tor 规范、tor 和 Arti 的源代码、Tor Project 的提案以及研究论文——并在正文中注明出处。

第一部分 — 历史与基础

匿名性与元数据；混合网络（mix network）与匿名转发邮件服务（remailer）；从美国海军研究实验室（NRL）的洋葱路由到 Tor Project；Tor 的威胁模型，以及它无法防范的情形。

第二部分 — 协议底层

Tor 中的密码学；网络架构；通道与链路协议（link protocol）；信元；电路建立（CREATE_FAST、 ntor、ntor-v3）；RELAY 信元的分层加密与新的 CGO 方案；流（stream）；SENDME 与拥塞控制；目录系统；路径选择与入口守卫（guard）；v3 洋葱服务；DoS 防御；审查、网桥与可插拔传输。每章都以一个实验结束。

第三部分 — Tor 实践

用 torrc 配置 tor；控制端口与 Stem；搭建私有 Tor 网络；用 Wireshark 分析流量；运行洋葱服务、中继和网桥；Tor 浏览器、Tails 与 Whonix；Tor Metrics 与 OONI；意大利和欧盟的法律与伦理问题。

第四部分 — 攻击与防御

流量关联、网站指纹识别（website fingerprinting）、女巫攻击（Sybil）、真实案例和操作失误。本书采取分析与防御的视角：解释攻击为何有效、Tor 如何应对，不提供针对他人的操作指南。

第五部分 — 研究与未来

关于 Tor 的学术研究、Arti（用 Rust 实现的 Tor）、尚未解决的问题以及 Tor Project 当前的提案。
