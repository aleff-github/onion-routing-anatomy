实验

二十个实验逐步构建 torlab——一个用 Python 编写的小型教学用 Tor 客户端：通道、信元、握手、加密、流、目录、路径选择、洋葱服务等等。

私有 Tor 网络

代码运行在一台电脑上的私有 Tor 网络中：tor 0.4.9.13 和 Chutney 在 Docker 镜像中从源代码编译，所有服务只监听 127.0.0.1。任何流量都不会离开这台机器。

这些实验只为这个私有网络而设计，绝不会针对公共中继或真实用户进行，遵循 Tor Research Safety Board 的原则。

经过验证，而不只是描述

2026 年 10 月 28 日，所有意大利语版实验都在私有网络上重新实机运行：53/53 项检查通过，另外 obfs4 网桥实验 14/14 项通过。离线测试无需 Docker 或网络即可检查代码和脚本。验证摘要保存在代码仓库中。

动手试试

git clone https://github.com/aleff-github/onion-routing-anatomy
cd onion-routing-anatomy
make -C labs/it test       # 离线测试（Python 3.11 或更高版本）
make -C labs/it immagine   # 构建包含 tor 和 Chutney 的 Docker 镜像
make -C labs/it avvia      # 启动私有网络
make verifica-lab          # 重新运行所有实验并检查结果

分步指南位于 labs/it/wiki（意大利语）。 labs/<语言>/wiki 中的翻译版指南属于正在审校的译本。
