# Лабораторная среда — русский язык

Этот каталог содержит русскую учебную среду для книги *Анатомия Tor*.

Исходные файлы и документация этой редакции находятся в отдельном каталоге. Комментарии, диагностические сообщения и пользовательские пояснения локализованы, а идентификаторы протокола, тестовые векторы и ожидаемое поведение сохраняются. **Разделение каталогов не означает изоляцию контейнеров или сети:** EN, RU и ZH-CN используют общие имена образа Docker `torbook-lab:latest` и контейнера `torbook-network`, одинаковые порты хоста и `--network host`. Не запускайте их одновременно.

Содержимое:

- `лаборатория/` — приватная сеть Tor, образ Docker и лабораторные сценарии;
- `код/` — русский учебный клиент `torlab`, тесты и воспроизводимые контрольные данные;
- `вики/` — русская документация лабораторных работ 1–20.

Активные эксперименты разрешено выполнять **только в контролируемой приватной сети Chutney**, не на публичных ретрансляторах Tor и не на сторонних сервисах. Режим `--network host` использует сетевое пространство имён хоста и не обеспечивает сетевую изоляцию; используйте контролируемую тестовую машину. `лаборатория/net/` хранит закрытые ключи и идентичности узлов — **не публикуйте его**.

Из корня репозитория:

```bash
make -C labs/ru test
make -C labs/ru image
make -C labs/ru start
make -C labs/ru verify
```

Файлы других языков находятся в отдельных каталогах `labs/<язык>/`, однако запущенные сети EN/RU/ZH-CN используют общие имена ресурсов Docker и пересекающиеся порты хоста.

## Область действия команд

- `make -C labs/ru test` запускает модульные тесты `torlab`, **но не все 20 лабораторных экспериментов**.
- `make -C labs/ru verify` запускает эти тесты, а затем проверку сети Chutney. Успех не подтверждает работоспособность всех отдельных лабораторных сценариев.
- `make -C labs/ru data` по явному запросу загружает публичный исторический файл CollecTor по HTTPS. Скрипт проверяет **только заголовок формата**, но не подписи консенсуса и сертификаты центров каталогов.
- `make -C labs/ru stop` сохраняет `лаборатория/net/`, тогда как `make -C labs/ru clean` **безвозвратно удаляет созданные ключи, идентичности и состояние из `лаборатория/net/`**.

Для оболочки контейнера используйте `make -C labs/ru/лаборатория shell`. Чтобы запустить топологию моста obfs4 из 12 узлов, остановите обычную сеть, проверьте и очистите только ненужные временные данные, затем выполните `make -C labs/ru/лаборатория start NETWORK=book-bridge`. В отличие от `book` с 10 узлами, мостовая топология не содержит onion-сервиса. Подробности: [README лаборатории](лаборатория/README.md).
