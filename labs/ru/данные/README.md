# Публичные исторические данные исследований

Лаборатории **7, 15 и 19** используют архивный консенсус Tor. Тестовый
консенсус из приватной сети Chutney **не заменяет** исторический публичный
документ, необходимый для численных результатов книги.

Из корня репозитория:

```bash
make -C labs/ru data
```

Сценарий по запросу загружает архив Tor Project CollecTor за сентябрь 2026
года и извлекает `2026-09-23-15-00-00-consensus-microdesc` в
`labs/ru/данные/collector/consensus-microdesc-2026-09-23-15`.
Проверяется только **формат заголовка**, но не подлинность подписей.
Для полного воспроизведения нужны сертификаты соответствующих
центров и реальные тестовые прогоны.

Загрузка использует обычное HTTPS, не посылает экспериментальный трафик
на публичные узлы Tor. Скачанные данные исключены из Git.
