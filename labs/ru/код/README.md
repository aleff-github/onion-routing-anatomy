# torlab — учебный клиент Tor (русская среда)

Пакет Python `torlab` сопровождает лабораторные работы книги *Анатомия Tor*. Он реализует отдельные части настоящего протокола Tor в учебных целях и предназначен **только для приватной лабораторной сети**, описанной в [`../README.md`](../README.md). Это не полноценный клиент Tor и не средство обеспечения анонимности.

## Предусмотренные проверки

Из **корня репозитория**, при наличии Python 3.11+, `pytest` и `cryptography`:

```bash
PYTHONPATH=labs/ru/код python3 -m pytest -q labs/ru/код/torlab/test
make -C labs/ru test
```

Команды обращаются к русскоязычному пакету, а не к историческому итальянскому каталогу `labs/it/codice/torlab/`. Локальные модульные проверки **не подтверждают** совместимость с действующей сетью Tor или безопасность клиента.

## Модули пакета

| Модуль | Лаб. | Назначение |
|---|---:|---|
| `channel.py` | 1 | TLS-соединение, начальные ячейки и проверка идентичности ретранслятора |
| `cells.py` | 2 | ячейки фиксированной и переменной длины, сообщения ретрансляции |
| `ntor.py` | 3 | согласование ключей ntor и ntor-v3 |
| `encryption.py`, `circuit.py` | 4 | послойное шифрование и расширение цепочки |
| `stream.py` | 5 | потоки и управление SENDME |
| `directory.py` | 6 | консенсус, сертификаты и микродескрипторы |
| `path_selection.py` | 7 | взвешенный выбор маршрута |
| `onion.py` | 8 | адреса и дескрипторы onion v3 |
| `pow.py` | 9 | пороговая проверка Blake2b с **имитацией** решений Equi-X |
| `traffic.py` | 12 | разбор расшифрованного TLS-трафика |
| `metrics.py` | 15 | статистика консенсуса |
| `simulation.py` | 19 | моделирование времени до компрометации |
| `conversion.py` | прил. B | преобразование ключей и перекрёстная сертификация |
| `laboratory.py` | служебный | адреса узлов и порты приватной сети |

Для других лабораторных работ предусмотрены отдельные скрипты в `../лаборатория/`. Подписанные данные и криптографические тестовые векторы должны сохраняться **побайтно** и не переводятся. Модуль `pow.py` **не реализует Equi-X**: решения имитируются для исследования уровня Blake2b.

## Ограничения и безопасность

В учебном клиенте нет полного управления перегрузкой, смены цепочек, дополнения трафика и всех средств защиты от анализа трафика. **Не используйте его для реальной анонимности, передачи конфиденциальных данных или экспериментов в публичной сети Tor.** Для защиты приватности используйте актуальные официальные версии Tor или Arti. Приватная лабораторная сеть сама по себе не обеспечивает изоляцию от операционной системы компьютера.
