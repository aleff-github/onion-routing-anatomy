# torlab — Учебный клиент Tor (русское издание)

Этот небольшой учебный пакет Python сопровождает лабораторные работы книги в **частной сети Tor**. Он **не** является полноценным клиентом или средством обеспечения анонимности. Не используйте его для защиты реальных личных данных и не направляйте интерактивные эксперименты на публичные ретрансляторы. Для практического применения используйте Tor Browser или Arti. Описание частной сети: [`../../лаборатория/`](../../лаборатория/README.md).

### Запуск тестов

Из **корня репозитория** после установки необходимых Python-зависимостей в изолированном окружении:

```bash
PYTHONPATH=labs/ru/код python3 -m pytest -q labs/ru/код/torlab/test
```

Для PowerShell:

```powershell
$env:PYTHONPATH = "labs/ru/код"
python -m pytest -q labs/ru/код/torlab/test
```

Эти команды приводятся для воспроизводимости, **не как подтверждение успешного тестирования**. Файлы `test/data/` содержат криптографические и захваченные тестовые данные: при переводе их байты не изменяют.

### Границы реализации и источники данных

- **Лаборатория 7:** учитываются веса консенсуса (`bwweightscale`), идентификаторы узлов и IPv4 `/16`, но не полные ограничения семейств, политики выхода, IPv6 или постоянные Guard. Лабораторный консенсус не заменяет архивный публичный консенсус.
- **Лаборатория 8:** исторические образцы позволяют изучать подписи сертификатов и шифрование. По умолчанию `check_expiration=False` применяется для архивных данных; при работе с актуальными данными нужно отдельно проверять срок и подлинность директории. Restricted discovery и полная проверка introduction points не реализованы.
- **Лаборатория 9:** `required_attempts()` использует случайные **16-байтовые заменители**, а не решения Equi-X. После `max_attempts` (по умолчанию **10 000**) может возникнуть `RuntimeError`. Прохождение порога Blake2b **не является** действительным PoW Tor.
- **Лаборатории 12, 15 и 19:** анализ трасс, статистика и симуляция требуют соответствующих исходных данных. Для публичных исторических примеров необходимы отдельно проверенные архивы; частная сеть их не заменяет. Симуляция не гарантирует анонимность.

Имена API, байты протокола и криптографические тестовые векторы сохраняются без перевода. Динамические тесты и сетевые проверки остаются в ожидании.
