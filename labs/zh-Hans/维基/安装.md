# 安装与准备

本指南适合第一次使用本书仓库的读者，从一台尚未配置实验环境的计算机开始。

## 系统要求

| 组件 | 用途 | 检查命令 |
|---|---|---|
| **Docker** | 运行完整的私有 Tor 网络；也可用于构建图书 | `docker run --rm hello-world` |
| **Python 3.11+** | 教学用 `torlab` 客户端 | `python3 --version` |
| **`cryptography`** | X25519、Ed25519 与 AES | `python3 -c "import cryptography; print(cryptography.__version__)"` |
| **`pytest`** | 代码单元与回归测试 | `python3 -m pytest --version` |
| **Rust（`cargo`）** | **仅实验 20**，用于构建 Arti | `cargo --version` |

从仓库根目录安装 Python 依赖（取决于本机的虚拟环境与系统配置）：

```bash
python3 -m pip install -r requirements.txt
```

无需在宿主机单独安装 `stem`：实验 11、16 和 18 在已经包含 Stem 的容器内运行。

磁盘空间：Docker 镜像、tor 源码和网络状态预计需要约 **3 GB**。为实验 20 编译 Arti 可能还需要约 **2 GB**。

**操作系统：**原始实验在 Linux 上开发和测试。macOS 中的 Docker 运行在虚拟机里，`--network host` 的行为与 Linux 不同，因此可能需要调整网络环境；使用环回接口 `lo` 抓包的实验 10 和 12 不能保证按原样运行。Windows Docker Desktop 也应先确认网络行为。

## 第一步：构建实验镜像

```bash
make -C labs/zh-Hans/实验室 image
```

构建过程中将从源码编译 tor 0.4.9.13，并安装 Chutney、obfs4proxy、snowflake-client、`tshark` 和 `curl`。第一次运行需要下载多个依赖，可能持续数分钟。

为什么不直接安装发行版提供的 tor？

- Dockerfile 固定了 tor 版本（`ARG TOR_VERSION`），有助于重复本书中的实验。
- 使用 `--enable-gpl` 构建，以启用洋葱服务工作量证明模块（第 15 章、实验 9）；不要假设任何第三方构建都采用了相同选项。
- 可以直接检查 `src/core/or/` 中的源码，当规范无法完全解释观察到的行为时，源码尤其重要。

检查构建的版本：

```bash
docker run --rm torbook-lab:latest tor --version
```

## 第二步：启动私有网络

```bash
make -C labs/zh-Hans/实验室 start
```

它会创建 `torbook-network` 容器，由 Chutney 为十个节点生成配置和密钥，并等待引导完成。EN、RU、ZH-CN 共用 Docker 镜像标签和容器名称，且使用宿主机网络端口；不能同时启动多种语言的实验网络，切换前应先停止已有的容器。私有网络中的目录权威节点每 20 秒投票一次。

运行端到端验证：

```bash
make -C labs/zh-Hans/实验室 verify
```

原始实验中曾观察到 `successes:4 failures:0`。这是供对照的历史结果，**不是中文版最近一次实际测试的结论**。如果失败，请参见[故障排查](故障排查.md)。

## 第三步：验证教学代码

从仓库根目录运行中文版独立的测试：

```bash
make -C labs/zh-Hans test
```

也可以直接运行：

```bash
PYTHONPATH=labs/zh-Hans/代码 python3 -m pytest -q labs/zh-Hans/代码/torlab/test
```

这些 Python 测试不需要公共 Tor 网络，其实际数量和结果必须执行后确认。Chutney 网络检查与每个实验的专用脚本属于不同的验证步骤；实验 7、15、19 的数值还依赖对应的历史共识数据。原始环境的 53 项检查不是中文版已通过的证据。

随后使用[自动验证指南](自动验证.md)逐项运行涉及网络的实验脚本。

## 第四步（可选）：构建中文版图书

在完整仓库和合适的 LaTeX 环境中运行：

```bash
make -C source/zh-Hans check
make -C source/zh-Hans pdf
make -C source/zh-Hans epub
```

还可以生成印刷版与封面。**当前版本尚未完成实际的全量构建和视觉校对**；本指南提供命令，不表示构建已经验证。

## 停止或清理私有网络

```bash
make -C labs/zh-Hans/实验室 stop     # 停止节点，保留实验目录和密钥
make -C labs/zh-Hans/实验室 clean    # 同时删除 labs/zh-Hans/实验室/net/
```

`labs/zh-Hans/实验室/net/` 存放测试节点的私钥，不在 Git 中进行版本管理，也不应公开。虽然这些密钥只属于隔离的玩具网络，也应养成避免泄露密钥的习惯。
