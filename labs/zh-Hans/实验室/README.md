# 实验用私有 Tor 网络

简体中文版的主动实验**仅用于受控的 Chutney 私有网络**，不得针对公共 Tor 中继或第三方服务。完整设置见第 19 章；本文件提供快速参考。**Docker 使用 `--network host`，与宿主机共享网络命名空间，因此不具备容器级网络隔离。**请只在受控测试主机上运行实验。

## 目录内容

| 文件或目录 | 用途 |
| --- | --- |
| `Dockerfile` | 从源码编译 Tor 0.4.9.13，使用 `--enable-gpl` 启用洋葱服务工作量证明模块所需功能；包含 Chutney、obfs4proxy、snowflake-client、Stem、tshark 和 curl |
| `Makefile` | 提供 `image`、`start`、`verify`、`status`、`shell`、`stop` 和 `clean` 目标 |
| `chutney/networks/book` | 大多数实验使用的默认网络 |
| `chutney/networks/book-bridge` | 实验 10 使用的网桥权威、obfs4 网桥及其客户端；不包含洋葱服务 |
| `net/` | 自动生成的节点配置、私钥、日志和状态；不纳入 Git 版本控制 |
| `*.py` | 实验 11、13、14、16、17、18 和 20 的示例脚本 |

## 使用命令

在 `labs/zh-Hans/实验室/` 目录内执行（也可在仓库根目录使用 `make -C labs/zh-Hans/实验室 <目标>`）：

```bash
make image     # 首次使用前构建私有实验镜像
make start     # 启动默认 Chutney 拓扑并执行引导
make verify    # Chutney 端到端网络检查，并非所有实验的验证
make status    # 查看 Chutney 节点状态
make shell     # 进入实验容器的 shell
make stop      # 停止节点并删除容器，保留 net/
make clean     # 停止网络并删除 net/，包括生成的密钥和节点身份
```

实验 10 使用 `make start NETWORK=book-bridge`，但**必须先停止现有网络，并检查或清理其可丢弃的状态**。网桥拓扑有 **12 个节点**，不是 10 个，而且不包含洋葱服务。仓库根目录的意大利语 `make riavvia` 目标只操作**意大利语**容器，不能用于重启中文版实验环境。

EN、RU、ZH-CN 三个环境的 Makefile 共用镜像名和容器名（`torbook-lab:latest`、`torbook-network`），也使用相互冲突的宿主机端口。**不得同时运行这些版本的实验网络。**

## 默认 `book` 拓扑

十个节点，配置在本机地址 `127.0.0.1` 上：

| 节点 | 角色 | ORPort | ControlPort | 其他端口 |
| --- | --- | --- | --- | --- |
| `000a`–`002a` | 目录权威兼中继 | 5100–5102 | 8000–8002 | DirPort 7100–7102 |
| `003r`–`005r` | 中间中继 | 5103–5105 | 8003–8005 | — |
| `006e`、`007e` | 仅面向本地私有目的地址的出口中继 | 5106、5107 | 8006、8007 | 目的地址段 `127.0.0.0/8` |
| `008c` | 客户端 | — | 8008 | SocksPort 9008 |
| `009h` | 洋葱服务 | — | 8009 | 虚拟端口 5858 → `127.0.0.1:4747` |

Chutney 按节点编号约定：**仅中继角色**使用 ORPort `5100+n`，使用 ControlPort `8000+n`，而**客户端**使用 SocksPort `9000+n`。不能据此认为客户端或洋葱服务具有中继 ORPort。意大利语原文称目录权威约每 20 秒投票一次，但**实际投票和共识生成时间仍须通过运行测试确认**。

## 故障排查

- **`address already in use`**：宿主机端口可能已被程序或其他语言版本的实验网络占用，例如 4747 或 8080 上的本地 HTTP 服务。停止冲突进程后再尝试；`--network host` 不会避免端口冲突。
- **节点显示运行却无响应**：异常停止后可能残留旧的 `pid` 文件。重启前检查 Chutney 状态；根目录的意大利语 `riavvia` 目标不适用于 ZH-CN。
- **第一次未成功建立电路**：小规模测试网络可能出现暂时性失败；如果持续复现则需要诊断。重新运行不等于验证通过。
- **客户端无法启动**：Chutney 可能需要第二启动阶段（`CHUTNEY_LAUNCH_PHASE=2`）。应检查客户端日志与拓扑，不能仅凭 `make start` 就认定启动成功。
- **`make start` 运行中途失败**：Makefile 不会自动回滚部分创建的容器或网络。重试前检查状态和日志；`make clean` 会不可恢复地删除生成的节点身份。

## 安全提示

本目录部分脚本会故意产生异常流量、畸形 Tor cell（信元）或受控探测。**只能在一次性、私有的 Chutney 实验网络中运行。**不要针对公共中继或真实在线服务执行，否则可能干扰他人，并可能违法（第 25 章）。`net/` 中存放实验私钥，**不得公开**。书中的输出来自参考运行；你的运行结果在细节上可能不同。
