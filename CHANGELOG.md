# Changelog

Changes to the book and the project, by version. All language editions share the edition and
the version number; release tags carry the language (`vX.Y.Z-<language>`). The rules are in
[docs/editorial-process.md](docs/editorial-process.md). Within a version, changes are grouped
as **Editorial corrections**, **Technical corrections**, **Laboratories**, **Translations**
and **Website and documentation**; entries link the issue or pull request and credit its
author ([CONTRIBUTORS.md](CONTRIBUTORS.md)).

## 1.0.0 — First edition (published 2026-11-10)

First edition of *Anatomia di Tor — Il protocollo dell'anonimato, byte per byte*.

- **License and distribution:** the whole work (text, figures, cover, LaTeX sources,
  laboratory code and documentation) is free software under GPL-3.0-or-later and is
  distributed free of charge.
- **Content:** 31 chapters, 4 appendices, 176 exercises with solutions, 39 figures, 20
  laboratories on a private Tor network. Reference versions: tor 0.4.9.13, Arti 2.6.0.
- **Italian edition (original), release `v1.0.0-it`:** PDF A4 (298 pages), EPUB 3, PDF
  7×10 in for personal printing (342 pages), digital cover (PNG, SVG). The Italian
  laboratories were run live on the private network on 28 October 2026: 53/53 checks, plus
  14/14 for the obfs4 bridge laboratory.
- **English, Spanish, Russian and Simplified Chinese editions:** first edition, version
  1.0.0, translated with artificial-intelligence tools from the Italian original. The
  repository contains their sources, laboratories and freely downloadable PDF/EPUB/cover
  editions in `book/<language>/`, made publicly available as downloads on 11 November 2026.
  They have not been independently reviewed by native speakers. **The GitHub release
  `v1.0.0-it` contains only the Italian original**; translations can be downloaded directly
  from the repository. Four separate language releases were published on 11 November 2026:
  [en](https://github.com/aleff-github/onion-routing-anatomy/releases/tag/v1.0.0-en),
  [es](https://github.com/aleff-github/onion-routing-anatomy/releases/tag/v1.0.0-es),
  [ru](https://github.com/aleff-github/onion-routing-anatomy/releases/tag/v1.0.0-ru) and
  [zh-Hans](https://github.com/aleff-github/onion-routing-anatomy/releases/tag/v1.0.0-zh-Hans)
  ([all editions](book/README.md), [review details](docs/translation-review.md)).
- **Documentation:** README, AI disclosure ([AI_DISCLOSURE.md](AI_DISCLOSURE.md)),
  contribution guide, code of conduct, security policy, editorial process, translation review
  guide, and a multilingual website generated by `scripts/build_site.py`.
