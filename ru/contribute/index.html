Помогите улучшить книгу

Это свободная книга, открытая для предложений и исправлений, которые помогают улучшать текст и лабораторные работы.

Как можно помочь

  • Сообщить об опечаткеОрфографическая ошибка, пропущенное слово, неясная фраза.
  • Исправить переводНеверный или неестественный фрагмент перевода.
  • Техническое исправлениеНеверное или устаревшее утверждение о Tor.
  • Проблема в лабораторииРабота ведёт себя не так, как описано.
  • Предложить улучшениеНовый материал, более понятное объяснение, иллюстрация.
  • Проверка переводовПроверьте главу на своём языке.
  • Внести текст или кодОткройте pull request.
  • Улучшить документациюREADME, руководства, инструкции.

Без Git и LaTeX

Нужна только учётная запись GitHub. Выберите тип сообщения, заполните форму — язык, главу или страницу, текущий текст и ваш вариант — и отправьте её. Этого достаточно: изменение в исходниках внесёт кто-то другой.

Небольшую опечатку можно исправить и самостоятельно: откройте файл на GitHub, нажмите на значок карандаша, измените текст и выберите «Propose changes». GitHub сам создаст копию репозитория и pull request; собирать книгу не нужно.

С Git

  1. Сначала откройте issue, если это не мелкое исправление.
  2. Найдите файл: итальянский текст — в source/it/, переводы — в source/<язык>/, код лабораторных работ — в labs/.
  3. Сделайте форк репозитория, создайте ветку и внесите изменение.
  4. Запустите подходящие проверки: для make check и make test нужен только Python, для сборки книги — Docker.
  5. Откройте pull request и ответьте на замечания рецензента.

Подробности — в CONTRIBUTING.md (на английском и итальянском).

Что происходит дальше

Каждое сообщение читается и получает статус: требует проверки, подтверждено, в работе, предложено исправление, решено, не воспроизводится или дубликат. Изменения в описании протокола, криптографии или лабораторных работ требуют первоисточника или воспроизводимого доказательства; для опечатки достаточно быстрой проверки. Принятые исправления попадают в следующую версию книги и перечисляются в журнале изменений. Процесс описан в docs/editorial-process.md.

Благодарности

Те, чьи изменения приняты, перечислены в CONTRIBUTORS.md под именем на GitHub или под выбранным ими именем. Любой может попросить не указывать его. Никаких рейтингов нет.

Полезно знать

  • Вклад принимается на условиях лицензии проекта, GPL-3.0-or-later.
  • Не размещайте в публичных issue персональные данные, закрытые ключи, записи трафика и другие чувствительные материалы.
  • О проблемах безопасности в коде или лабораторных работах сообщайте конфиденциально: см. SECURITY.md.
  • Все участники следуют короткому кодексу поведения.
