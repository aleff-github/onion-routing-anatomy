Лаборатории

Двадцать лабораторных работ шаг за шагом создают torlab — небольшой учебный клиент Tor на Python: канал, ячейки, рукопожатия, шифрование, потоки, каталоги, выбор пути, onion-сервисы и многое другое.

Частная сеть Tor

Код запускается в частной сети Tor, которая живёт на одном компьютере: tor 0.4.9.13 и Chutney, собранные из исходников в образе Docker, все службы слушают только 127.0.0.1. Ничто не покидает машину.

Эксперименты рассчитаны только на эту частную сеть. Они никогда не проводятся на публичных ретрансляторах или реальных пользователях — в соответствии с принципами Tor Research Safety Board.

Проверено, а не только описано

28 октября 2026 года все итальянские лабораторные работы были заново выполнены в частной сети: пройдено 53/53 проверки, плюс 14/14 для работы с мостом obfs4. Офлайн-тесты проверяют код и скрипты без Docker и без сети. Итоги проверки находятся в репозитории.

Попробуйте сами

git clone https://github.com/aleff-github/onion-routing-anatomy
cd onion-routing-anatomy
make -C labs/it test       # офлайн-тесты (Python 3.11 или новее)
make -C labs/it immagine   # образ Docker с tor и Chutney
make -C labs/it avvia      # запуск частной сети
make verifica-lab          # повторный запуск всех работ и проверка результатов

Пошаговые руководства находятся в labs/it/wiki (на итальянском). Переведённые руководства в labs/<язык>/wiki входят в переводы, которые ещё проверяются.
