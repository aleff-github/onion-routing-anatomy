Help improve this book

This is a free and open book: contributions help improve its explanations, code and laboratories.

Ways to help

  • Report a typoA spelling mistake, a missing word, an unclear sentence.
  • Fix a translationA wrong or awkward passage in a translation.
  • Technical correctionA statement about Tor that is wrong or out of date.
  • Laboratory problemA laboratory that does not behave as described.
  • Propose an improvementNew content, a better explanation, a figure.
  • Join the translation reviewReview a chapter in your language.
  • Contribute code or textOpen a pull request.
  • Improve the documentationREADME, guides, instructions.

Without Git or LaTeX

You only need a GitHub account. Choose the kind of report, fill in the form — the language, the chapter or page, the current text and what you would write instead — and submit it. That is enough: the change to the sources will be made by someone else.

For a small typo you can also propose the fix yourself: open the file on GitHub, click the pencil icon, change the text and choose “Propose changes”. GitHub creates a copy of the repository and a pull request for you; the book does not need to be built.

With Git

  1. Open an issue first, unless the change is a small fix.
  2. Find the file: the Italian text is in source/it/, translations in source/<language>/, laboratory code in labs/.
  3. Fork the repository, create a branch and make the change.
  4. Run the checks that fit the change: make check and make test need only Python; building the book needs Docker.
  5. Open a pull request and answer the review.

The details are in CONTRIBUTING.md.

What happens next

Every report is read and given a state: to verify, confirmed, in progress, fix proposed, resolved, not reproducible or duplicate. Changes to the protocol description, the cryptography or the laboratories need a primary source or a reproducible proof; a typo needs only a quick check. Accepted corrections go into the next version of the book and are listed in the changelog. The process is described in docs/editorial-process.md.

Credit

People whose contributions are accepted are listed in CONTRIBUTORS.md, under the GitHub name or the name they choose. Anyone can ask not to be listed. There are no rankings.

Good to know

  • Contributions are accepted under the project's license, GPL-3.0-or-later.
  • Do not put personal data, private keys, packet captures or other sensitive material in public issues.
  • Security problems in the code or the laboratories are reported privately: see SECURITY.md.
  • Everyone is expected to follow the short code of conduct.
