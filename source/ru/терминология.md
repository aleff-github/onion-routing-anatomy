# Терминология русского издания

Английское издание в `source/en/` является основным редакционным источником. Идентификаторы протокола, имена сообщений, поля, команды, API, параметры и константы не переводятся.

| English source term | Русская форма | Правило |
|---|---|---|
| relay | реле Tor / ретранслятор | В главах часто используется «реле»; в приложении A также «ретранслятор». Оба варианта обозначают relay, а не маршрутизатор общего назначения. |
| guard relay / guard | входной узел (guard) / guard-реле | В главе 13 предпочтительно «входной узел (guard)»; `Guard` как флаг/токен Tor не переводить. |
| middle relay / middle | промежуточное реле / промежуточный узел | `middle` сохранять в англоязычных именах ролей и протокольных контекстах. |
| exit relay / exit | выходной узел / выходное реле (exit) | Для роли в повествовании употреблять «выходной узел»; официальный флаг `Exit` не переводить. |
| circuit | цепь | Единообразно во всём издании. |
| channel | канал | |
| cell | ячейка | |
| link protocol | протокол связи (link protocol) | Как в приложении A: это версионированный протокол канала, не общее название транспорта. |
| handshake | рукопожатие / обмен начальными сообщениями | Различать TLS-рукопожатие и обмен ячейками при установлении канала Tor; не заменять все случаи на «обмен ключами». |
| relay cell | RELAY-ячейка | Когда имеется в виду тип ячейки протокола. |
| stream | поток | |
| directory authority | центр каталогов (directory authority) | Как в приложении A; при пояснении допустимо «сервер каталогов». Указывать оригинальный термин при первом определении. |
| consensus | консенсус | |
| descriptor | дескриптор | |
| microdescriptor | микродескриптор | |
| onion service | onion-сервис | `hidden service` использовать только в историческом контексте. |
| introduction point | точка введения | |
| rendezvous point | точка рандеву | |
| bridge | мост | |
| pluggable transport | подключаемый транспорт | |
| traffic analysis | анализ трафика | |
| traffic correlation | корреляция трафика | |
| website fingerprinting | распознавание сайтов по трафику (website fingerprinting) | Совпадает с приложением A; «фингерпринтинг» допустим при пояснении англоязычных источников. |
| threat model | модель угроз | |
| forward secrecy | прямая секретность (forward secrecy) | Английский термин полезно сохранять при первом определении. |
| flow control | управление потоком | |
| congestion control | управление перегрузкой | |
| padding | заполнение (padding) | |
| family | семейство | Для Tor relay family. |
| family key | ключ семейства | Ключ принадлежности ретрансляторов к семейству; не путать с blinded key onion-сервиса. |
| blinded key | ослеплённый ключ (blinded key) | |
| proposal | proposal / предложение Tor | Номер proposal всегда сохраняется. |

Стиль: современный технический русский, без буквального копирования английского синтаксиса. Нормативные слова MUST, MUST NOT, SHOULD, SHOULD NOT и MAY сохраняются как формальные токены RFC, когда они присутствуют в исходнике; перевод рядом не должен менять силу требования.
