# 简体中文版术语表

本文件记录《Tor 解剖》简体中文版的核心术语选择。正式协议术语、命令名、常量和 API 标识符不得为了“汉化”而随意改写。

| English term | 简体中文 | 使用规则 |
|---|---|---|
| onion routing | 洋葱路由 | 首次出现可写“洋葱路由（onion routing）”。 |
| relay | 中继 | 不要泛化为“路由器”；只有一般性说明时才可用“节点”。 |
| guard relay / guard | 入口守卫（guard）/ 守卫中继 | 与附录 A 和第 13 章一致；官方标志 `Guard` 保持原样。 |
| middle relay / middle | 中间中继 / 中间节点 | 协议路径角色优先用“中间中继”。 |
| exit relay / exit | 出口中继 / 出口 | 上下文明确时使用“出口”。 |
| cell | 信元（cell）/ cell（信元） | 首次出现保留英文 `cell`；后续“信元”或 `cell` 均可。命令名 `RELAY`、`VERSIONS` 等保持原样。 |
| relay cell | RELAY 信元 / RELAY cell | 指承载 relay 消息的信元，不要与 relay 消息或中继节点混淆。 |
| circuit | 电路 | Tor 的多跳逻辑路径。 |
| stream | 流 | 指 Tor 电路上复用的应用流。 |
| channel | 通道 | 指中继之间的底层连接。 |
| link protocol | 链路协议 | 不改写成 transport protocol。 |
| handshake | 握手 | |
| directory authority | 目录权威 | |
| consensus | 共识 | |
| descriptor | 描述符 | |
| microdescriptor | 微描述符 | |
| onion service | 洋葱服务 | “hidden service”仅用于历史语境。 |
| introduction point | 引介点 | |
| rendezvous point | 汇合点 | |
| bridge | 网桥 | 首次出现可写“网桥（bridge）”。 |
| pluggable transport | 可插拔传输 | 首次出现保留英文括注。 |
| blinded key | 盲化密钥 | |
| family key | 家族密钥 | 中继家族的成员认证密钥；不可与洋葱服务盲化密钥混用。 |
| forward secrecy | 前向保密 | |
| traffic analysis | 流量分析 | |
| traffic correlation | 流量关联 | |
| flow control | 流量控制 | 通过窗口与 SENDME 防止接收端负载过高；与拥塞控制不同。 |
| congestion control | 拥塞控制 | 基于网络状况控制在途数据量；不要与流量控制混用。 |
| threat model | 威胁模型 | |
| path selection | 路径选择 | |
| proposal | 提案 | 必须保留提案编号。 |

写作风格采用清晰、克制的大学技术教材语体。句子应自然符合现代标准汉语，而不是逐句照搬英语语序。教学顺序保持原书结构：动机 → 机制 → 底层细节 → 具体示例。
