\section*{第 \ref{cap:23-browser} 章：Tor Browser、Tails 与 Whonix}

\begin{soluzione}{es:23-identita}
\enquote{为此网站使用新电路}只更换当前标签页所属网站的电路，不会清除 Cookie、浏览历史或其他网站的状态；网站仍可能凭借已存储的状态识别用户。\enquote{新身份}则关闭所有标签页、清除浏览器状态，并为后续活动重新建立电路。二者都不更换守卫，因为频繁轮换会提高最终选中恶意守卫的概率（\cref{sec:guard}）。无论如何，入口守卫都看不到客户端访问了哪些网站。
\end{soluzione}

\begin{soluzione}{es:23-estensioni}
用户可能阻止更多跟踪器加载，但 Tor Browser 已按网站隔离跟踪器，并限制持久标识符。安装扩展会牺牲用户之间的统一性：网站可能检测扩展是否存在或采用何种过滤列表，使用户与 Tor Browser 的其他大量用户区别开来。扩展还会增加一批能够访问网页内容的代码。
\end{soluzione}

\begin{soluzione}{es:23-isolamento}
如果访问同一网站的两个标签页使用相同 SOCKS 凭据，tor 会把它们的流附加到同一电路。使用不同凭据的第三个标签页会获得另一条电路。\texttt{GETINFO stream-status} 可以显示每条流对应的电路标识符。
\end{soluzione}

\begin{soluzione}{es:23-scelta}
（a）Tor Browser 已经足够，可能还需要使用网桥。（b）Tails：从 USB 设备启动，通常不会在他人计算机上留下痕迹，只保留用户主动放入加密持久存储的数据，但仍需考虑遭到攻破的硬件。（c）Whonix：Workstation 上的应用在架构上只能通过 tor 联网，而且系统支持长期运行的工作，不要求像 Tails 一样具有遗忘性。
\end{soluzione}

\begin{soluzione}{es:23-impronta}
这是开放式练习。可选择的特征包括屏幕与窗口尺寸、时区、语言、可用字体和 Canvas 渲染结果。在普通浏览器中，这些特征可能泄露从几个比特（例如时区）到大量比特（例如字体和 Canvas 特征）的信息。Tor Browser 利用 letterboxing 对尺寸取整、报告 UTC 与统一语言、限制字体，并标准化或禁用易泄露信息的接口。仍然存在的差异包括操作系统、选择的安全级别以及取整后的显示尺寸。
\end{soluzione}

\section*{第 \ref{cap:24-metrics} 章：网络测量}

\begin{soluzione}{es:24-dieci}
目录请求数量会减少一半，而用户估计仍使用固定除数 10，因此估计用户数也会减少一半。随着新版 tor 普及，图表会显示多个国家几乎同时发生、幅度很大的下降。如果这种全球性变化与软件采用率相关，就应怀疑客户端行为发生了变化，而不是用户大量流失。估算方法需要采用修正后的除数。
\end{soluzione}

\begin{soluzione}{es:24-frazione}
估计用户数为 $20\,000\,000/(0.6\cdot10)\approx3\,333\,333$。如果报告覆盖比例只有 8\%，由于低于 10\% 的最低要求，估计结果会被丢弃。
\end{soluzione}

\begin{soluzione}{es:24-flag}
思路：筛选同时具有两个标志的中继，将其带宽之和除以全网带宽。计算出口选择概率时，使用实验~7 的 \texttt{probabilities(consensus, "exit")}，找出出现次数最多的五个 /16 网络，再对所属中继的选择概率求和。
\end{soluzione}

\begin{soluzione}{es:24-censura}
这是开放式练习。有明确记录的封锁事件通常会在开始封锁当天，使直接连接用户估计数明显下降。接下来几天，随着受影响用户改用其他传输技术，网桥用户估计数，尤其是 Snowflake 或 WebTunnel 的用户数，可能上升。Metrics 可能把最初下降的日期标为异常。
\end{soluzione}

\begin{soluzione}{es:24-privacy}
如果没有舍入，攻击者知道自己是某个国家唯一访问某中继的用户，或精确知道其他用户数量时，就可以检查额外信息统计，以计数是否增加 1 判断这个国家的另一个人是否连接。舍入可以隐藏这种小幅变化。但控制大量中继的攻击者并不需要公开计数，因为他可以直接观察进入自己中继的连接。
\end{soluzione}

\section*{第 \ref{cap:25-legale} 章：法律与伦理}

\begin{soluzione}{es:25-condizioni}
（a）出口如果主动向网站发起请求，例如为了\enquote{混合}流量，就构成主动发起传输。（b）出口如果把连接重定向到不同于 \texttt{BEGIN} 指定的目的地，就参与选择接收方。（c）出口如果向 HTTP 页面插入内容，或者按语义过滤信息，就参与选择或修改信息。这些行为也可能导致中继被标记为 \texttt{BadExit}。
\end{soluzione}

\begin{soluzione}{es:25-strumento}
厨房刀具本身合法，但用它实施伤害行为违法。通过 Tor 阅读遭到审查的报纸，可能属于合法使用合法工具；但未经授权访问计算机，不论是否使用 Tor，都可能构成犯罪。中继运营者只提供传输能力，不选择内容，因此更接近承运者而非作者，前提是运营者没有参与违法活动。具体法律结论始终取决于司法辖区和案件事实。
\end{soluzione}

\begin{soluzione}{es:25-segnalazione}
说明该地址属于 Tor 出口，可通过 Tor Project 的公开工具核实；运营者不知道、也不记录客户端身份，因此无法识别用户；投诉网站如果愿意，可以对公开出口地址的连接采取区别处理措施。在实践中，如果运营收益超过因此带来的限制，运营者也可以增加一条拒绝该网站地址的出口策略规则。
\end{soluzione}

\begin{soluzione}{es:25-esperimento}
该计划在未获得同意的情况下观察真实用户的流量，收集访问域名等可能泄露个人信息、不适合公开的数据，而预期收益有限。因此，它违反多项研究安全原则，在意大利还可能涉及刑法与数据保护问题。更安全的替代方案包括使用已公开的 Metrics 汇总数据，只用研究人员自己的 Tor 客户端测量新闻网站可达性，或者请 Research Safety Board 审查一种采用聚合与噪声、类似中继统计的隐私保护计数方案。
\end{soluzione}

\begin{soluzione}{es:25-ricerca}
这是研究练习。应检索官方司法数据库，例如意大利法院公开的裁判或欧盟法院文书，而不只是依赖第三方摘要。对于每份裁判，记录法院、日期、适用法律和结果，并区分涉及中继运营者的案件与涉及 Tor 用户的案件。
\end{soluzione}

\section*{第 \ref{cap:26-attacchi} 章：关联、指纹识别与 Sybil 攻击}

\begin{soluzione}{es:26-posizione}
流量关联需要通过中继或底层网络同时观察通信两端；守卫、路径约束和测量带宽可以提高攻击成本。网站指纹识别只需要观察客户端到守卫的链路；目前只有效果有限的填充防御，相关研究仍在进行。发现守卫需要占据中间中继位置并诱发电路建立；守卫与 Vanguards 有助于防御。Sybil 攻击者运营大量中继；防御包括带宽测量、家族、/16 约束和网络监控。路由攻击需要影响自治系统或互联网交换点；应对措施包括 Tor 协议之外的 BGP 监控。
\end{soluzione}

\begin{soluzione}{es:26-base}
在 100\,000 次访问中，预期正确警报约为 0.95 次，而误报约为 $0.001\cdot99\,999\approx100$ 次。因此正确警报占比为 $0.95/(0.95+100)\approx0.9\%$。几乎所有警报都是误报。
\end{soluzione}

\begin{soluzione}{es:26-bin}
如果以两秒为一个区间，却只观测五秒，每条序列只有两三个样本，相关性会变得很不稳定。如果让所有客户端采用相同的流量节奏，例如使用相同随机种子，时间序列会几乎完全相同，匹配就无法区分。统一流量节奏尤其会破坏关联，这也是 PipeNet 恒定速率通信的基本思想（\cref{sec:radici-bassa}）。
\end{soluzione}

\begin{soluzione}{es:26-difesa}
恒定传输速率使入口流量时间序列不再变化。此时方差为零，Pearson 相关系数在数学上没有定义，或者主要由网络噪声决定，因此这种攻击失效。代价是即使没有有效数据，也必须按选定的最高速率持续发送。实验中，这可能意味着每名客户端每秒发送数十或数百 KB，比真正的应用数据多出数倍。
\end{soluzione}

\begin{soluzione}{es:26-probabilita}
固定守卫时，只有当选中恶意守卫，攻击者才可能成功，其概率约为 5\%。发生这种情况后，约 5\% 的电路还会经过恶意出口。在六个月的高强度使用中，至少一次失守的概率因此接近 5\%；在这个简化模型中，选择诚实固定守卫的用户始终不会失守。每条电路都重新随机选择守卫时，单条电路失守概率约为 $0.05\cdot0.05=0.0025$；经过数千条电路后，至少一次失守几乎必然发生。这说明持久守卫的意义，实验~7 的 \texttt{Adversary} 类也可通过模拟验证。
\end{soluzione}

\section*{第 \ref{cap:27-casi-rete} 章：真实网络攻击案例}

\begin{soluzione}{es:27-campo}
在发往客户端的路径上，每台中继会给信元载荷增加自己的加密层（\cref{cap:10-cifratura-relay}）。守卫收到的载荷受到中间跳点的密钥保护，因此无法读取 HSDir 写入其中的内容。外层信元命令则属于每台中继都会读取、并原样转发的头部。
\end{soluzione}

\begin{soluzione}{es:27-uno}
使用三台守卫时，至少一台为恶意中继的概率大约是只用一台时的三倍，每台恶意守卫还会观察客户端的部分流量。只用一台守卫可以降低选择风险；如果选中诚实守卫，客户端会长期受到保护。缺点是，如果唯一守卫恶意，它就能观察该客户端的全部入口流量；而守卫过慢或不可访问，也会影响连接质量。
\end{soluzione}

\begin{soluzione}{es:27-verso}
实验本来就使用 \texttt{DROP} 信元，而不是扩展请求。\file{command.c} 中的计数器在解密前检查外层信元命令，因此与内部中继消息无关。在相反方向，源码会记录警告并使用 \texttt{PROTOCOL} 原因码关闭电路，无论电路属于客户端还是中继。
\end{soluzione}

\begin{soluzione}{es:27-segnali}
可能的迹象包括：中继在完全相同的分钟加入共识、描述符中罕见但相同的 tor 版本与操作系统、同一网络或托管商的地址、类似的端口和昵称，以及缺少联系信息。误报情况包括合法大型运营者同时更新全部中继、广泛使用的托管服务商，以及使用相同配置的自动部署。没有单一信号能够证明所有权相同；应组合证据，并尽可能联系运营者。
\end{soluzione}

\begin{soluzione}{es:27-canali}
中间中继能看到明文外层元数据：CircID（每跳都会变化，因此不会原样穿过电路）；信元命令，包括 \cella{RELAY} 和 \cella{RELAY\_EARLY}，这是 2014 年攻击利用的信道：如今朝向客户端的方向已被封闭，反方向则被限制为八个信元；\cella{DESTROY} 及其原因码；还有信元的时间和数量。最后两项仍能用于被动确认，目前没有完全有效的防御。载荷采用分层加密，但在 tor1 中，恶意中继可以修改它并让另一台恶意中继识别（\cref{sec:tor1-debolezze}）。CGO（\cref{sec:cgo}）使此类修改导致后续跳点得到无法恢复的明文，从而阻止这种标记。
\end{soluzione}
